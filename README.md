# 114-YEAR-BONUS
# 114年國軍年終獎金試算系統 (114 Year Military Bonus Calculator)

這是一個專為中華民國國軍官兵設計的**114年年終與考績獎金快速試算網頁工具**。採用單一 HTML 檔案架構，無需安裝任何後端環境或依賴套件，開啟瀏覽器即可即時計算預估領取的獎金總額。

## ✨ 主要功能

1. **雙模式計算切換**
   * **對照表查詢模式**：內建114年國軍各階級（軍官、士官、士兵）之本俸級距、專業加給與主管職務加給資料庫，只需選擇階級與俸級即可自動帶入金額。
   * **自訂輸入模式**：支援手動輸入薪資條上的「本俸」、「專業加給」與「主管職務加給」，方便特殊加給或個人化試算。

2. **智慧考績與領導職判定**
   * **領導職切換**：軍官與士官階級可一鍵切換「領導職 / 非領導職」，系統會自動加減算「主管職務加給」（士兵階級自動隱藏此選項）。
   * **滿級數自動偵測**：當選擇各階級之最高俸級（滿級數，一兵與二兵除外）時，考績選項會自動切換為「**滿級數 (2.0 個月)**」與「乙上 (0.5 個月)」；一般俸級則提供「**甲等 (1.0 個月)**」與「乙上 (0.5 個月)」。

3. **即時試算與發放日程提示**
   * 底部固定資訊欄即時顯示**月支數額**、**年終獎金 (1.5個月)**、**考績獎金**以及**預估領取總額**。
   * 內建預計發放日程提醒（農曆春節前10日，預計 115/2/6 發放）。

4. **行動裝置優先設計 (Mobile-First)**
   * 採用響應式設計，介面針對手機螢幕比例最佳化，提供流暢的觸控與滾動體驗。

## 🛠️ 技術架構

* **HTML5 / Vanilla JavaScript**：純原生前端邏輯，輕量快速，零外部 JS 框架依賴。
* **Tailwind CSS (CDN)**：使用 Tailwind CSS 打造現代化、高對比且易讀的 UI 介面。
* **Google Fonts**：引入 `Noto Sans TC`（思源黑體）與 `Roboto Mono`（等寬數字字體），確保金額對齊與閱讀清晰度。

## 🚀 如何使用

1. 下載專案中的 HTML 檔案（例如 `index.html`）。
2. 直接使用任何現代瀏覽器（Chrome、Safari、Edge、Firefox 等）開啟該檔案即可使用。
3. 亦可直接部署至 GitHub Pages、Vercel 或 Netlify 等靜態網頁託管平台，方便透過手機連結分享給同袍使用。

## 📐 計算公式說明

系統依據以下公式進行四捨五入計算：

* **月支計算基準** = $\text{本俸} + \text{專業加給} + \text{主管職務加給（若為領導職）}$
* **年終工作獎金** = $\text{月支計算基準} \times 1.5$
* **考績獎金** = $\text{月支計算基準} \times \text{考績倍數（0.5 / 1.0 / 2.0）}$
* **預估領取總額** = $\text{年終工作獎金} + \text{考績獎金}$

本工具之薪資數據係依據「114年國軍年終考績獎金金額表」建置，試算結果與預計發放日期僅供參考，實際發放金額與入帳時間仍以國防部及各單位財務部門核定為準。
